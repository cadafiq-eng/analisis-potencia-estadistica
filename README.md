# 📊 Análisis de Potencia Estadística

Aplicación interactiva para el análisis de potencia y error tipo II en pruebas de hipótesis.

## 🚀 Acceso Directo
👉 [**Abrir Aplicación**](https://kgog9gvctubhgdtnpbsksp.streamlit.app/)

## 📚 Funcionalidades

- ✅ Pruebas de hipótesis sobre la media
- ✅ Pruebas de hipótesis sobre proporciones
- ✅ Pruebas de hipótesis sobre varianza
- ✅ Pruebas F para razón de varianzas
- ✅ Comparación de múltiples escenarios
- ✅ Visualizaciones interactivas
- ✅ Exportación a Excel y PDF

## 👨‍🏫 Uso Educativo

Esta herramienta está diseñada para estudiantes y profesores de estadística.

## 📖 Instrucciones

1. Abre la aplicación
2. Selecciona el tipo de prueba
3. Ajusta los parámetros con los sliders
4. Observa cómo cambian la potencia y los errores
5. Descarga los resultados si lo necesitas
